# รอบ 2S — ค้นหาโปรแกรมที่ดีที่สุดจริง

> สัญญาที่ทุกคนยึดในรอบนี้ | PM เป็นเจ้าของ | 23 ก.ย. 2026

---

## 1. ทำไม

รอบ 2L วัดหกโปรแกรมแล้วพบว่า **ไม้บรรทัดของเราคดมาตั้งแต่รอบ 2P** — โปรแกรม "คนคิดเป็น" ที่ใช้จูน
เกณฑ์ B1–B5 แพ้โปรแกรมสองบรรทัด และโปรแกรมผู้พิทักษ์ที่ PM เดาไว้แพ้คนบรรทัดเดียวทุกชั้น
**สองในสามอาชีพ เรายังไม่รู้ว่าโค้ดที่ดีหน้าตาเป็นยังไง**

ทุกอย่างที่อยากทำต่อ — จูนการล็อกเลเวลรายภูมิภาค · ตัดสินว่าบทเรียนโซนไหนจริง · ตัดสินว่าต้องมีมอนกลไกไหม —
ต้องการคำตอบข้อเดียวกันก่อน: **โปรแกรมที่ดีที่สุดที่ผู้เล่นเขียนได้จริง ของแต่ละอาชีพ ในแต่ละที่ คืออะไร**
รอบนี้หาคำตอบนั้นด้วยการค้น ไม่ใช่การเดา

## 2. ตัวชี้วัด: "โค้ดนี้ประหยัดเลเวลให้คุณกี่เลเวล"

ต่อ (อาชีพ × ภูมิภาค × รอบ) หนึ่งช่อง:

```
เลเวลขั้นต่ำ(โปรแกรม) = เลเวลต่ำสุดที่โปรแกรมนี้ชนะ ≥ 80% (ของแบบผู้เล่นจริงที่ชั้นนั้น)
ค่าของโค้ด            = เลเวลขั้นต่ำ(บรรทัดเดียว) − เลเวลขั้นต่ำ(โปรแกรมที่ดีที่สุด)
```

เลือกตัวนี้เพราะมันคือ **คำสัญญาของเกมพอดี** — "โค้ดดีขึ้นแล้วผ่านเร็วขึ้น" เป็นหน่วยเลเวล
และมันให้ตารางล็อกรายภูมิภาคฟรี: ล็อกที่ `เลเวลขั้นต่ำ(ดีที่สุด)` แล้วคนบรรทัดเดียวจะขาดไปเท่ากับ "ค่าของโค้ด" พอดี
ช่องไหนค่าของโค้ด ≈ 0 = ช่องนั้นโค้ดไม่มีผล **ล็อกเลเวลเท่าไรก็สร้างกำแพงไม่ได้** ต้องใช้กลไกมอน

## 3. สิ่งที่ค้น — และกติกาที่ทำให้ผลเชื่อได้

**พื้นที่ค้น** (ไวยากรณ์ที่ผู้เล่นเขียนได้จริง ตรวจด้วย validator ตัวจริงทุกโปรแกรม):
- บรรทัดเดียว: ทุกการกระทำ × ทุกตัวเลือกเป้า
- `if / else`: ทุกเงื่อนไข × ทุกคู่การกระทำ
- `if / elif / else`: ต่อยอดจากตัวที่ดีที่สุดของชั้นก่อน (ค้นเต็มพื้นที่แพงเกินไป — บันทึกข้อจำกัดนี้ไว้ตรง ๆ)

**กติกาที่มาจากความผิดพลาดของรอบก่อน ๆ:**
1. **วัดรายภูมิภาค ห้ามเฉลี่ยรวมชั้น** — รอบ 2L ภูเขาไฟที่เป็นไปไม่ได้จมอยู่ในค่าเฉลี่ย 88%
2. **ของแบบผู้เล่นจริง** — ดรอปที่ชั้นนั้น ระดับ uncommon ไม่อัปเกรด ห้ามใช้ของในอุดมคติ
3. **โปรแกรมต้องเขียนได้จริงที่ชั้นนั้น** — ตรวจกับความสามารถที่ปลดแล้วตอนมาถึงครั้งแรก
4. **บิลด์เดียวกันทุกโปรแกรม** ในอาชีพเดียวกัน — ให้ต่างกันแค่โค้ด

## 4. เกณฑ์รับงาน

| # | เกณฑ์ | วัดยังไง |
|---|---|---|
| **S1** | การค้นต้องเจอโปรแกรมที่ดีเท่าหรือดีกว่าทุกโปรแกรมที่ PM เคยเลือกเอง | ต้องเจอ "ดาบหมุนเมื่อ ≥3 ตัว" ของนักรบซ้ำเอง หรือเจอตัวที่ดีกว่า |
| **S2** | **ทดสอบแบบพยายามล้ม:** เอเจนต์อิสระเขียนโปรแกรมด้วยมือเพื่อชนะตัวที่ค้นเจอ | ถ้าชนะได้ = พื้นที่ค้นไม่ครบ ต้องรายงาน ไม่ใช่ซ่อน |
| S3 | ตาราง "ค่าของโค้ด" ครบสามอาชีพ ทุกภูมิภาค ทุกรอบ | ไฟล์ผลใน `docs/measurements/` |
| S4 | ตารางล็อกรายภูมิภาคที่ได้จากข้อ 2 ยืนยันบนเซิร์ฟเวอร์จริง | ทำแบบ L1 ของรอบ 2L — แบบจำลองเชื่อไม่ได้จนกว่าจะเล่นจริง |

S2 คือเกณฑ์ที่สำคัญที่สุด: การค้นที่ไม่มีใครพยายามล้ม คือการเดาอีกแบบหนึ่งที่ดูน่าเชื่อกว่าเดิม
