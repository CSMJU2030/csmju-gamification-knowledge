# รอบ 2L — ล็อกเลเวลในภูมิภาค

> สัญญาที่ทุกคนยึดในรอบนี้ | PM เป็นเจ้าของ | 22 ก.ย. 2026
> เจ้าของโปรเจกต์เลือก: **ล็อกเลเวลในภูมิภาค หอคอยปล่อย**

---

## 1. ทำไมต้องมีรอบนี้

รอบ 2F วัดกับเซิร์ฟเวอร์จริง 6 รอบ: คนเขียน `attack(weakest(enemies))` บรรทัดเดียว **จบเกมทั้ง 6 รอบ**
และทางที่เร็วที่สุดคือแพ้ซ้ำ ๆ ที่ชั้นหน้า (ชนะ 10 แพ้ 28 แล้วจบ) — ดู `docs/measurements/fix-after-2f.txt`

สาเหตุรากที่รอบ 2F ไม่ได้แตะ: **ไม่มีชั้นไหนในเกมที่เลเวลเพิ่มแล้วไม่ช่วย**
EXP สะสมจากไหนก็ได้ สะสมไปเรื่อย ๆ ก็ชนะทุกชั้นในที่สุด ลด EXP ลงแค่ทำให้ช้าลง

รอบนี้แก้ที่รูปทรงของปัญหา ไม่ใช่ที่ตัวเลข: **ในภูมิภาค เลเวลที่เกินมาจะถูกตัดทิ้ง**

---

## 2. หน้าที่ของสองที่ต่างกันชัดเจน

| | หอคอย | ภูมิภาค |
|---|---|---|
| เลเวล | ตามจริง ไม่ล็อก | **ล็อกไว้ที่เลเวลของโซน** |
| อุปกรณ์ | ตามจริง | **ปรับลงตามชั้นของโซน** |
| หน้าที่ | ทางพลัง — ฟาร์ม ของ เลเวล ปลดภาษา | **หลักสูตร — ต้องผ่านด้วยโค้ด** |
| คนขี้เกียจ | ผ่านได้ด้วยการฟาร์ม (ตั้งใจ) | **ต้องตัน** |

หอคอยปล่อยไว้โดยตั้งใจ: มันคือที่ที่ผู้เล่นทุกคนยังก้าวหน้าได้ ปลดภาษาได้ครบ และเก็บของได้
ภูมิภาคคือที่ที่เกมทำตามสัญญา "โค้ดดีขึ้นแล้วผ่าน" ได้จริงเป็นครั้งแรก

---

## 3. ล็อกอะไรบ้าง — และทำไมล็อกแค่เลขเลเวลไม่พอ

PM ตรวจ `engine/src/stats.ts` แล้ว: เลขเลเวลโผล่ในสูตรแค่สองที่ (`maxHp +10/เลเวล` · `maxMp +2/เลเวล`)
พลังจริงมาจาก `str/vit/int` ซึ่งได้มา **จากการเลเวลอัพ** (5 แต้มต่อเลเวล)
ถ้าล็อกแค่เลขเลเวล นักรบเลเวล 21 ที่มี STR 81 จะยังมี STR 81 ในโซนเลเวล 10 = การล็อกที่รั่ว

**ล็อกสามอย่างพร้อมกัน:**

1. **เลเวล** → `min(เลเวลจริง, เลเวลของโซน)`
2. **สเตตัส** → ย่อแต้มที่ได้จากการเลเวลลงตามสัดส่วน
   `stat = ค่าตั้งต้นของอาชีพ + (stat - ค่าตั้งต้น) × (เลเวลโซน - 1) / (เลเวลจริง - 1)`
   **รักษารูปทรงของบิลด์ไว้** — คนที่ตีเยอะจนเป็นสาย STR ยังเป็นสาย STR เพียงแต่แต้มรวมเท่ากับ
   คนเลเวลนั้นจริง ๆ ระบบความชำนาญของรอบ 2P จึงยังมีความหมายในภูมิภาค
3. **อุปกรณ์** → ทุกชิ้นทำตัวเหมือนดรอปที่ชั้นของโซน
   `droppedFloor → min(droppedFloor, ชั้นโซน)` · `upgradeLevel → min(upgradeLevel, ชั้นโซน)`
   ค่าอัฟฟิกซ์ย่อตาม `ชั้นโซน / droppedFloor`
   ถ้าไม่ล็อกของ คนขี้เกียจจะฟาร์มของจากหอคอยแล้วเอามาตีภูมิภาค — รูเดิมเปิดกลับ

ล็อกลงอย่างเดียว ไม่ดึงขึ้น: ผู้เล่นที่เลเวลต่ำกว่าโซนสู้ด้วยค่าจริงของตัวเอง

---

## 4. เลเวลของโซน — วัด ไม่ใช่เดา

ตาราง `gamedata.balance.levelSync` หนึ่งค่าต่อชั้น (1–10)
**เลือกด้วยเครื่องมือ** `engine/tools/syncprobe.cjs` ที่กวาดเลเวลล็อกทีละชั้น
แล้ววัด **อัตราผ่านของโปรแกรมคิดเป็น เทียบกับโปรแกรมบรรทัดเดียว** — ที่ของดีที่สุดที่หอคอยให้ได้

เกณฑ์เลือก: ค่าต่ำสุดที่โปรแกรมคิดเป็นผ่าน ≥ 80% ของทุกอาชีพ
แล้วยืนยันว่าที่ค่านั้น โปรแกรมบรรทัดเดียวผ่าน ≤ 20%
ชั้นไหนหาค่าที่แยกสองกลุ่มออกจากกันไม่ได้ → รายงานตรง ๆ ว่าชั้นนั้นยังไม่มีกำแพง
**ห้ามบังคับให้ตัวเลขผ่าน** ชั้นตื้น ๆ ที่คนขี้เกียจผ่านได้เป็นเรื่องปกติ (เกณฑ์ B1 รอบ 2P บอกไว้แล้วว่า
คนไม่คิดควรไปถึงชั้น 4) กำแพงต้องอยู่ตรงกลางถึงปลายเกม ไม่ใช่ตั้งแต่ประตูแรก

---

## 5. ต้องประกาศก่อน — ห้ามซ่อน

กฎ §4 ของรอบ 2W: *"ดวงต้องไม่เป็นตัวตัดสิน · ผู้เล่นต้องเห็นก่อนเริ่ม"*
การล็อกเลเวลที่ผู้เล่นไม่รู้ตัว จะรู้สึกเหมือน "เลเวล 20 แล้วทำไมยังแพ้โซนชั้น 5" — แพ้โดยไม่รู้สาเหตุ
คำประกาศตอน `enter` จึงต้องบอก: **"ในโซนนี้คุณจะสู้ที่เลเวล X"** และบัตรโซนบนแผนที่ก็ต้องบอกด้วย
และเพราะคำประกาศบอกแล้วว่าเลเวลช่วยไม่ได้ ข้อความนั้นเองคือบทเรียน: *ที่นี่ต้องใช้โค้ด*

---

## 6. รางวัล

การรบในภูมิภาคใช้ **ตัวละครที่ถูกล็อกแล้ว** ทั้งการรบและการคิดรางวัล
= สู้แบบยุติธรรม ได้รางวัลแบบยุติธรรม (farmFalloff ของรอบ 2F ไม่ลงโทษ เพราะคุณอยู่เลเวลเท่าโซน)
EXP ที่ได้ไปเข้า **เลเวลจริง** ของผู้เล่นตามปกติ — ใช้ในหอคอยได้ แต่ถูกตัดทิ้งเมื่อกลับเข้าภูมิภาค

การดวลไม่แตะ — แบ่งตามช่วงเลเวลอยู่แล้ว และเป็นแมตช์แยกที่ไม่มีรางวัล (§5.3 รอบ 2W)

## 7. เกณฑ์รับงาน

| # | เกณฑ์ | วัดยังไง |
|---|---|---|
| **L1** | **คนขี้เกียจที่ฟาร์มหอคอยจนจบแล้ว ต้องตันในภูมิภาคช่วงกลางถึงปลาย** | เซิร์ฟเวอร์จริง: ฟาร์มหอคอยจบ → ใส่ของดีที่สุด → ท้าทุกโซน |
| **L2** | โปรแกรมคิดเป็นเคลียร์ทุกโซนได้ที่เลเวลล็อก | เซิร์ฟเวอร์จริง ทุกโซน |
| **L3** | ของจากหอคอยไม่เปิดรูกลับ | วัด L1 ซ้ำโดยปิดการล็อกของ → ต้องเห็นความต่าง (พิสูจน์ว่าข้อ 3.3 จำเป็น) |
| L4 | `npm run tune -w engine` ยังผ่าน B1–B5 | หอคอยไม่ถูกแตะ |
| L5 | คำประกาศ `enter` และบัตรโซนบอกเลเวลที่ล็อก | ยิง API + ดูหน้าจอ |
| L6 | เทสต์ของฟังก์ชันล็อก: แต้มรวมเท่าคนเลเวลนั้นจริง · รูปทรงบิลด์คงเดิม · ของถูกล็อก | mutation test ทุกข้อ |

**L1 คือเกณฑ์จริง** — บทเรียนจากรอบ 2F: เกณฑ์หลักตกได้แม้ทุกข้ออื่นผ่านหมด
และวัดด้วย **หลายกลยุทธ์ขี้เกียจ** (ถอยไปฟาร์ม · ไม่ถอยเลย) เพราะรอบที่แล้วแบบจำลองวัดแค่
กลยุทธ์เดียว แล้วพลาดกลยุทธ์ที่ดีกว่า
