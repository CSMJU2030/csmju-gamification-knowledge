## 1. บันทึกโปรแกรมที่ถูกปฏิเสธ

(รูปแบบทุกรายการ: โค้ดที่เขียน · ข้อความที่ได้ · คิดว่าแปลว่าอะไร · แก้ได้จากข้อความนั้นอย่างเดียวไหม)

### ❌ #1 — ลืม `:` ท้าย def

```python
def turn()
    attack(weakest(enemies))
```

> `SyntaxError` — **"ลืมเครื่องหมาย : ท้ายบรรทัด def turn()"** (line 1, col 12)

**คิดว่าแปลว่า:** ลืมโคลอน ใส่โคลอนสิ
**แก้ได้จากข้อความนี้อย่างเดียวไหม:** ✅ ได้ทันที 1 ครั้ง
ข้อความนี้ดีมาก เพราะมันไม่ได้บอกแค่ "ผิดตรงไหน" แต่**ยกบรรทัดที่ผิดมาให้ดู**และบอกว่าต้องเติมอะไร

### ❌ #2 — `if` / `else` (โค้ดถูกตามหลัก Python ทุกอย่าง)

```python
def turn():
    if me.hp < 50:
        defend()
    else:
        attack(weakest(enemies))
```

> `LockedFeatureError` — **"คำสั่ง if / else ยังไม่ปลดล็อก — ต้องผ่านชั้น 1 ก่อน"** (line 2, col 5)

**คิดว่าแปลว่า:** โค้ดไม่ได้ผิด แต่เกมยังไม่ให้ใช้ ต้องไปชนะชั้น 1 มาก่อน
**แก้ได้จากข้อความนี้อย่างเดียวไหม:** ✅ ได้ — และนี่คือข้อความที่ดีที่สุดที่เจอทั้งรอบ

เหตุผลที่ดี: มันตอบคำถามที่ผู้เล่นจะถามต่อทันที ("แล้วต้องทำยังไงถึงจะใช้ได้") ไว้ในประโยคเดียว
ถ้าเขียนแค่ "if ยังใช้ไม่ได้" ฉันจะงงว่าเกมนี้ไม่มี if เลยหรือแค่ยังไม่ถึงเวลา — ต่างกันมาก

**สำคัญ:** ตอนนี้ฉันรู้แล้วว่าเลเวล 1 เขียนได้แค่ "เรียกฟังก์ชัน" อย่างเดียว ตรงกับ `unlockedFeatures:["call"]`

### ❌ #3 — เดาว่ามี `heal()`

```python
def turn():
    heal()
```

> `NameError` — **"ไม่รู้จักฟังก์ชัน 'heal()' — ดูรายการฟังก์ชันที่ใช้ได้ในหน้าช่วยเหลือ"**

**คิดว่าแปลว่า:** ไม่มีฟังก์ชันนี้ ให้ไปเปิดหน้าช่วยเหลือดูว่ามีอะไรบ้าง
**แก้ได้จากข้อความนี้อย่างเดียวไหม:** ❌ **ไม่ได้**

นี่คือ **ปัญหาใหญ่ที่สุดของรอบนี้** ข้อความสั่งให้ไป "หน้าช่วยเหลือ" แต่ผู้เล่นที่เล่นผ่าน API
ไม่มีหน้าช่วยเหลือให้เปิด ฉันไล่ยิงหาแล้วทุกชื่อที่นึกออก:

```
/help  /docs  /program/help  /program/functions  /program/reference
/language  /reference  /program/docs  /functions  /guide  /program/catalog
→ ทุกอันตอบ {"error":"ไม่พบ endpoint นี้"}
```

ข้อความชี้ไปยังที่ที่ไม่มีอยู่จริง **มันบอกว่าอะไรผิด แต่ไม่ได้บอกว่าให้ทำอะไรแทน**
สิ่งที่ฉันต้องการจริง ๆ คือ *รายชื่อฟังก์ชัน* — ถ้าใส่มาในข้อความเลยก็จบ เช่น
"ใช้ได้: attack(), defend(), wait()" แค่นี้ก็ไม่ต้องมีหน้าช่วยเหลือแล้ว

> `LockedFeatureError` — **"ข้อความในเครื่องหมายคำพูด ยังไม่ปลดล็อก — ต้องผ่านชั้น 2 ก่อน"**

## 2. วิธีที่ฉันหาคำสั่งเจอ (เพราะไม่มีคู่มือ)

พอรู้ว่าไม่มีหน้าช่วยเหลือให้เปิด ฉันเลยใช้ช่องโหว่หนึ่งที่ค้นพบเอง:
**ตัวตรวจโปรแกรมรายงานข้อผิดพลาด "ทุกบรรทัดพร้อมกัน" ไม่ได้หยุดที่อันแรก**
เลยเขียนโปรแกรมที่ยัดชื่อฟังก์ชันที่เดาไว้ 15-18 ชื่อ แล้วดูว่า**บรรทัดไหนไม่มี error** = บรรทัดนั้นมีจริง

ถือเป็นการเล่นแบบ binary search กับตัว validator — ได้ผลดีมาก แต่ก็สะท้อนว่า
ผู้เล่นต้อง *แฮ็กระบบ error* เพื่อให้ได้สิ่งที่คู่มือควรบอกตั้งแต่แรก
เด็ก 15 ที่เพิ่งหัดเขียนโค้ดจะไม่คิดวิธีนี้ออก

**ผลลัพธ์ที่ได้จากการยิงเดา 2 รอบ (รวม ~35 ชื่อ):**

| มีจริง | จำนวน argument |
|---|---|
| `attack(x)` | 1 — ต้องการ *ตัวละคร* |
| `defend()` | 0 |
| `wait()` | 0 |
| `cast(ชื่อสกิล, เป้า)` | 2 |
| `weakest(list)` `strongest(list)` `deadliest(list)` `fastest(list)` | 1 |
| `count(list)` | 1 |
| `len(list)` | มีจริง แต่**ล็อกถึงชั้น 13** |

ตัวแปร: `me`, `enemies`, `allies`, `turn_no`

**ที่เดาผิดหมด (ไม่มีจริง):** `heal` `print` `guard` `flee` `skill` `use` `item`
`nearest` `healthiest` `random` `first` `lowest` `highest` `toughest` `slowest`
`closest` `potion` `rest` `taunt` `shield` `block` `escape` `pass_turn` `idle` `sleep` `target` `allies()`

สังเกต: ฉันเดา `guard()` เพราะคำอธิบายอาชีพใน `/gamedata` เขียนว่า "ใช้ได้แค่โจมตี **ตั้งการ์ด** และรอ"
แต่ฟังก์ชันจริงชื่อ `defend()` — **คำอธิบายในเกมกับชื่อฟังก์ชันไม่ตรงกัน** ทำให้เดาผิด

### "คุณหมายถึง ... หรือเปล่า?" — บางครั้งช่วย บางครั้งมั่ว

ข้อความ NameError บางอันมีคำแนะนำต่อท้าย แต่คุณภาพไม่สม่ำเสมอ:

| พิมพ์ | เกมแนะนำ | ความเห็น |
|---|---|---|
| `nearest()` | "คุณหมายถึง `weakest()` หรือเปล่า?" | ✅ ช่วยจริง — ชี้ไปที่ตัวเลือกเป้าหมายที่มีอยู่ |
| `taunt()` | "คุณหมายถึง `count()` หรือเปล่า?" | ❌ มั่ว — คนละความหมายสิ้นเชิง แค่ตัวอักษรใกล้กัน |
| `rest()` | "คุณหมายถึง `cast()` หรือเปล่า?" | ❌ มั่ว |
| `flee()` | "คุณหมายถึง `len()` หรือเปล่า?" | ❌ มั่วที่สุด — แนะนำฟังก์ชันที่**ยังล็อกอยู่**ด้วยซ้ำ |

คำแนะนำคิดจาก "ตัวอักษรคล้ายกัน" อย่างเดียว ไม่ได้ดูความหมาย
สำหรับมือใหม่ คำแนะนำมั่ว ๆ **แย่กว่าไม่แนะนำเลย** เพราะฉันเสียเวลาไปลอง `count()` ตอนที่อยากได้ยั่วยุ

### ❌ #5 — `attack()` กับชนิดข้อมูลผิด

```python
def turn():
    attack(enemies)
    attack(me.hp)
    attack(count(enemies))
```

> `TypeError` — **"attack() ต้องการตัวละคร แต่ได้รับลิสต์ของตัวละคร"**
> `TypeError` — **"attack() ต้องการตัวละคร แต่ได้รับตัวเลข"**

**คิดว่าแปลว่า:** `enemies` เป็น "กอง" ต้องเลือกออกมาตัวหนึ่งก่อนถึงจะตีได้
**แก้ได้จากข้อความนี้อย่างเดียวไหม:** ✅ ได้ทันที

นี่เป็นข้อความที่**สอนแนวคิด**ได้จริง มันแยก "ลิสต์ของตัวละคร" กับ "ตัวละคร" ออกจากกันด้วยภาษาคน
ไม่ใช่ `expected Character, got Array<Character>` พอเห็นปุ๊บฉันเข้าใจทันทีว่า
`weakest()` มีหน้าที่อะไร — มันคือตัวแปลงจากลิสต์เป็นตัวละคร **ฉันเข้าใจภาษานี้จากข้อความ error นี้บรรทัดเดียว**

### ❌ #6 — เดาชื่อตัวแปรเอง

### ❌ #7 — `elif`

```python
def turn():
    if me.hp_pct < 30:
        defend()
    elif count(enemies) > 2:
        attack(deadliest(enemies))
    else:
        attack(weakest(enemies))
```

> `LockedFeatureError` — **"คำสั่ง elif ยังไม่ปลดล็อก — ต้องผ่านชั้น 4 ก่อน"**

**แก้ได้จากข้อความนี้อย่างเดียวไหม:** ⚠️ **ครึ่งเดียว**
มันบอกว่า "ยังใช้ไม่ได้ ต้องชั้น 4" ซึ่งชัดเจน **แต่ไม่ได้บอกว่าตอนนี้ให้เขียนยังไงแทน**
ฉันรู้จาก Python อยู่แล้วว่า `elif` = `else:` + `if` ซ้อน เลยแก้เองได้ใน 1 ครั้ง
แต่คนที่ไม่รู้ตรงนี้จะตัน — เขาจะคิดว่า "งั้นก็เขียนเงื่อนไข 3 ทางไม่ได้เลยจนถึงชั้น 4" ซึ่งไม่จริง
**ข้อความควรเติมประโยคเดียว: "ตอนนี้ใช้ `else:` แล้วซ้อน `if` ข้างในแทนได้"**

### ❌ #8 — `cast()` ตอนที่ยังไม่มี string

ปัญหาไก่กับไข่ที่น่าสนใจที่สุดในรอบนี้ ฉันได้สกิลมาจาก `/program`:
`m_firebolt` (ลูกไฟ, mp 7) และ `m_blizzard` (พายุน้ำแข็ง, mp 16, aoe)

ลองแบบที่ 1 — ใส่เป็นข้อความ:
```python
cast("m_firebolt", weakest(enemies))
```
> `LockedFeatureError` — "ข้อความในเครื่องหมายคำพูด ยังไม่ปลดล็อก — ต้องผ่านชั้น 2 ก่อน"

ลองแบบที่ 2 — ใส่เป็นชื่อเปล่า ๆ:
```python
cast(m_firebolt, weakest(enemies))
```
> `NameError` — "ไม่รู้จัก 'm_firebolt' — ใช้ได้เฉพาะ me, enemies, allies, turn_no ..."
> `TypeError` — **"cast() ต้องใส่ชื่อสกิลเป็นข้อความคงที่ เช่น `cast(\"firebolt\", weakest(enemies))`"**

**แก้ได้จากข้อความนี้อย่างเดียวไหม:** ✅ ได้ — เพราะ**มันยกตัวอย่างโค้ดที่ถูกมาให้ดู**
นี่คือรูปแบบข้อความที่ดีที่สุด: ไม่ใช่แค่บอกว่าผิด แต่**เขียนบรรทัดที่ถูกให้ดูเลย**

⚠️ **แต่มีกับดัก:** ตัวอย่างในข้อความเขียนว่า `"firebolt"` ส่วน API บอก id ว่า `"m_firebolt"`
สองอันไม่ตรงกัน ตอนนั้นฉันไม่รู้ว่าต้องพิมพ์อันไหน (จะไปทดสอบหลังผ่านชั้น 2)

## 3. บันไดปลดล็อกฟีเจอร์ (ที่ค้นเจอทีละอัน จากข้อความ error ล้วน ๆ)

ไม่มีที่ไหนบอกตารางนี้ ฉันประกอบมันขึ้นมาเองจากการโดนปฏิเสธ 7 ครั้ง:

| ฟีเจอร์ | ปลดที่ชั้น | ข้อความที่บอก |
|---|---|---|
| เรียกฟังก์ชัน | เริ่มมีเลย | — |
| `if` / `else` | 1 | "คำสั่ง if / else ยังไม่ปลดล็อก — ต้องผ่านชั้น 1 ก่อน" |
| ข้อความ `"..."` | 2 | "ข้อความในเครื่องหมายคำพูด ยังไม่ปลดล็อก — ต้องผ่านชั้น 2 ก่อน" |
| `elif` | 4 | "คำสั่ง elif ยังไม่ปลดล็อก — ต้องผ่านชั้น 4 ก่อน" |
| `and` / `or` / `not` | 6 | "ตัวเชื่อม and / or / not ยังไม่ปลดล็อก — ต้องผ่านชั้น 6 ก่อน" |
| สร้างตัวแปร | 8 | "การสร้างตัวแปร ยังไม่ปลดล็อก — ต้องผ่านชั้น 8 ก่อน" |
| `for` | 10 | "การวนซ้ำด้วย for ยังไม่ปลดล็อก — ต้องผ่านชั้น 10 ก่อน" |
| `+ - * /` และ `len()` | 13 | "การคำนวณ + - * / และ len() ยังไม่ปลดล็อก — ต้องผ่านชั้น 13 ก่อน" |

**ความเห็น:** ตัว *รูปแบบ* ข้อความนี้ดีมาก — "ชื่อฟีเจอร์ + ยังไม่ปลดล็อก + ต้องผ่านชั้นเท่าไหร่"
สม่ำเสมอทุกอัน อ่านครั้งเดียวรู้เรื่อง และทำให้ฉันไม่เสียเวลาคิดว่า "เกมนี้ทำไม่ได้เลยหรือเปล่า"

**แต่:** ฉันได้ตารางนี้มาด้วยการ*ชนกำแพงทีละอัน* ไม่มีที่ไหนให้ดูล่วงหน้าว่า
"ตอนนี้เขียนอะไรได้บ้าง / ต่อไปจะได้อะไร" `GET /program` คืน `unlockedFeatures` มาก็จริง
แต่เป็นรหัสดิบ (`["call","if_else","string","elif"]`) ไม่มีคำอธิบาย และไม่บอกว่ายังมีอะไรรออยู่

### ❌ #9 `and` · ❌ #10 ตัวแปร · ❌ #11 `for`

(โค้ดตามลำดับ — ทั้งสามได้ `LockedFeatureError` รูปแบบเดียวกัน แก้ได้จากข้อความทันทีทั้งหมด ✅)

```python
if me.hp_pct < 50 and count(enemies) > 1:   # ชั้น 6
target = weakest(enemies)                    # ชั้น 8
for e in enemies:                            # ชั้น 10
```

ข้อสังเกตเล็ก ๆ ที่ดี: ตอนเขียน `for e in enemies:` เกมฟ้อง **สองอัน**พร้อมกัน —
ทั้ง "for ยังไม่ปลดล็อก" และ "การสร้างตัวแปร ยังไม่ปลดล็อก" (เพราะ `e` คือตัวแปร)
มันเข้าใจว่า for สร้างตัวแปรด้วย ไม่ได้ฟ้องแค่ผิวเผิน

## 4. 🔴 สิ่งที่เข้าใจผิดแบบเงียบ ๆ (ไม่มี error แต่ทำงานไม่ตรงที่คิด)

**หมวดนี้อันตรายกว่า error ทุกอันข้างบนรวมกัน**

### 4.1 `cast()` ยอมรับสกิลที่ฉัน "ไม่มี"

`GET /program` บอกว่าฉันมีสกิล 2 อัน: `m_firebolt`, `m_blizzard`
แต่พอลองสุ่มพิมพ์ชื่ออื่น:

```python
cast("heal", weakest(enemies))    # → OK 200 ผ่านฉลุย
cast("bananas", weakest(enemies)) # → ValueError "ไม่มีสกิลชื่อ 'bananas' ในเกม"
```

ตัวตรวจถามแค่ว่า **"สกิลนี้มีในเกมไหม"** ไม่ได้ถามว่า **"ผู้เล่นคนนี้มีสกิลนี้ไหม"**
`heal` เป็นสกิลของอาชีพอื่น ฉันไม่เคยได้มา แต่โปรแกรมผ่าน — แล้วพอลงรบจริง:

```
newbie  skill m_heal  L2  →  เป้า: newbie  ฟื้น 0 HP
newbie  skill m_heal  L2  →  เป้า: newbie  ฟื้น 2 HP
```

มัน**ร่ายได้จริง**ด้วย ไม่ใช่แค่ผ่านตัวตรวจ (ฟื้น 0-2 HP เพราะ matk ฉันต่ำ)
ถ้าฉันเป็นมือใหม่จริง ๆ ฉันจะสรุปว่า "อ๋อ เกมนี้มี heal แต่มันห่วย" — ซึ่งผิดสองชั้น

### 4.2 🔴 argument ที่บอกเป้าหมาย ถูก "เมิน" เงียบ ๆ

อันนี้หนักที่สุด ฉันตั้งใจเขียนผิดเพื่อทดสอบ:

```python
def turn():
    cast("firebolt", me)      # ยิงลูกไฟใส่ตัวเอง
```
ผลในบันทึกการรบ: `firebolt → ก็อบลิน ดาเมจ 23` — **มันไปโดนก็อบลิน**

```python
def turn():
    attack(me)                # ตีตัวเอง
```
ผลในบันทึกการรบ: `attack → ก็อบลิน ดาเมจ 130 (ตาย)` — **มันไปโดนก็อบลินอีก**

ตอนตรวจโปรแกรม `attack(me)` ผ่าน (เพราะ `me` เป็น "ตัวละคร" ตรงชนิดที่ต้องการ)
แล้วตอนรบ เอนจินก็**เลือกเป้าให้เองเงียบ ๆ** ไม่ฟ้อง ไม่เตือน ไม่มีบรรทัดไหนในบันทึกบอกว่า
"เป้าที่คุณสั่งใช้ไม่ได้ ระบบเลือกให้แทน"

**ทำไมถึงร้ายแรง:** ทั้งเกมนี้สอนเรื่องเดียวคือ *"เลือกเป้าให้ถูก"*
บทเรียนทุกโซนพูดเรื่องนี้ — `deadliest` ที่ภูเขาไฟ, `weakest` ที่ซากปรักหักพัง
แต่ถ้าเขียนเป้าผิดแล้วเกม**แก้ให้เงียบ ๆ** ผู้เล่นก็จะไม่มีวันรู้ว่าตัวเองเข้าใจผิด
มือใหม่ที่เขียน `attack(me)` จะเห็นว่า "ก็ชนะนี่" แล้วเชื่อว่าตัวเองเข้าใจถูกแล้ว

### 4.3 🔴 โปรแกรมที่ไม่ได้โจมตีเลย ก็ยัง "ชนะ"

ตอนที่โปรแกรมฉันเป็น `cast("heal", weakest(enemies))` ล้วน ๆ
ฉัน **ไม่ได้โจมตีแม้แต่ครั้งเดียวทั้งการรบ** เอาแต่ฟื้นเลือดตัวเองทีละ 0-2 HP
ผลลัพธ์: `victory: True, wavesCleared: 10`

โซนเริ่มต้นชนะได้โดย**ไม่ต้องเขียนโค้ดที่ถูกเลย** ซึ่งแปลว่าช่วงที่ผู้เล่นกำลังหัด
เกมไม่ได้ให้ feedback ว่าโค้ดดีหรือแย่ — ชนะเหมือนกันหมด
ผู้เล่นจะเริ่มรู้ว่าตัวเองเขียนผิดก็ต่อเมื่อไปตายเอาที่ชั้นสูง ๆ ซึ่งห่างจากจุดที่ทำผิดมากแล้ว

### 4.4 เลือกอาชีพช้าไป 4 เลเวล — ไม่มีใครเตือน

เกมบอกว่า "เลือกอาชีพเมื่อผ่านชั้น 1" ฉันผ่านชั้น 1 แล้วขึ้นจากเลเวล 1 ไป **เลเวล 5 ในทีเดียว**
พอเลือก `mage` ปรากฏว่าแต้มที่ขึ้นมา 4 เลเวลนั้นลงไปทาง str หมดแล้ว (str 22, int 4)
→ เป็นจอมเวทที่มี **atk 49 / matk 15** เวทอ่อนกว่าต่อยเกือบ 4 เท่า

ไม่มี error ไม่มีคำเตือน และไม่มีทางแก้ ฉันรู้ตัวก็ตอนเห็นตัวเลขแล้ว
ผลคือทั้งเกมนี้ฉันเป็น "จอมเวทที่ต้องต่อย" — `cast()` ซึ่งเป็นฟีเจอร์ที่เกมอยากสอน
กลายเป็นตัวเลือกที่แย่กว่า `attack()` เสมอสำหรับฉัน

เป็นข้อความที่ทรมานมือใหม่ที่สุดใน Python จริง ๆ การบอกตัวเลขมาเลยตัดปัญหาทิ้งทั้งหมด

### ❌ #14 — `=` แทน `==`

✅ แก้ได้ทันที นี่คือข้อความที่**เดาเจตนาของผู้เขียนถูก**แล้วบอกทางแก้ตรง ๆ
รูปแบบ "คุณกำลังจะทำ X ใช่ไหม? งั้นเขียนแบบนี้" ควรใช้กับทุกข้อความในเกม

### ❌ #16 — `me.health`

✅ แก้ได้ทันที **ลิสต์มาครบทุกตัว** นี่คือสิ่งที่ข้อความ "ไม่รู้จักฟังก์ชัน" ควรทำแต่ไม่ทำ

### ❌ #17 — `enemies[0]`

### ❌ #18 — `enemies.length` 🔴 **ข้อความแนะนำทางแก้ที่ผิด**

```python

```
> `TypeError` — **"ลิสต์ไม่มีคุณสมบัติ .length — เลือกตัวก่อน เช่น `weakest(enemies).length`"**

**คิดว่าแปลว่า:** อ๋อ ต้องเลือกตัวก่อนแล้วค่อยจุด ตามตัวอย่างที่ให้มาเลย
เลยพิมพ์ตามตัวอย่างเป๊ะ ๆ:

if weakest(enemies).length > 1:

**นี่คือข้อบกพร่องที่ร้ายแรงที่สุดในบรรดาข้อความทั้งหมด** ตัวอย่างที่มันยื่นให้
(`weakest(enemies).length`) **ใช้ไม่ได้จริง** เพราะ `.length` ไม่ใช่คุณสมบัติที่มีอยู่เลยไม่ว่าจะกับอะไร
ดูเหมือนข้อความถูกสร้างจากแม่แบบ "เลือกตัวก่อน เช่น weakest(X).⟨ชื่อที่ผู้ใช้พิมพ์⟩"
โดยไม่ได้ตรวจว่าชื่อนั้นมีจริงไหม

สิ่งที่ฉันต้องการจริง ๆ คือ **`count(enemies)`** — ซึ่งมีอยู่ในเกม แต่**ข้อความไม่เอ่ยถึงเลยสักคำ**
ฉันแก้ได้เพราะรู้จัก `count()` มาก่อนแล้วจากการยิงเดาชื่อฟังก์ชันใน §2
**ถ้าไม่ได้ทำ §2 มาก่อน ตรงนี้คือทางตัน** — ลองตามตัวอย่างก็ผิด และไม่มีอะไรชี้ไปหา `count()`
รวมแล้วเสีย 2 ครั้ง และครั้งที่แก้ได้ไม่ได้มาจากข้อความ

**ของแถมที่ได้:** ศัตรูมีคุณสมบัติ**น้อยกว่า** `me` (hp, hp_pct, level, atk, speed เท่านั้น)
และข้อความบอกไว้ในวงเล็บว่า "คุณสมบัติเต็มชุดมีเฉพาะ me เท่านั้น" — ตรงนี้ดี ชัดเจน

### 🔴 ปัญหาเชิงระบบ: SyntaxError หนึ่งอัน กลบ error อื่นทั้งหมด

ตอนยิงเดาคุณสมบัติ ฉันเขียนโปรแกรมที่มี `me.health` (ผิด) อยู่บรรทัด 2

ปกติเกมนี้เก่งเรื่องฟ้องหลายอันพร้อมกัน (ดู §2 — ฟ้อง 15 อันรวดเดียว) แต่พอมี SyntaxError ปนมา
ความสามารถนั้นหายไปหมด มือใหม่จะเจออาการ "แก้ทีละอัน แล้วมีอันใหม่โผล่ไม่จบ"
ซึ่งทำให้รู้สึกว่าเกมกำลังแกล้ง ทั้งที่แค่ไม่ได้บอกว่ากำลังตรวจอยู่กี่ชั้น

## 6. 🔴 กฎที่เกมไม่เคยบอก: `turn()` ทำได้แค่ "หนึ่งการกระทำต่อเทิร์น"

มือใหม่ที่รู้ Python จะคิดว่า "โปรแกรมทำงานจากบนลงล่าง" ฉันเลยลองเขียนคอมโบ:

```python
def turn():
    attack(weakest(enemies))
    attack(weakest(enemies))
    attack(weakest(enemies))
```

> **`OK 200` — ผ่านฉลุย ไม่มีคำเตือนอะไรเลย**

แต่ในบันทึกการรบ:
```
turn 1 attack line 2 → หมาป่า 351
turn 2 attack line 2 → สไลม์ 195
turn 3 attack line 2 → ก็อบลิน 202
```

**ทุกเทิร์นมาจาก `line 2` เสมอ** บรรทัด 3 กับ 4 **ไม่เคยทำงานเลย**
เอนจินหยุดที่การกระทำแรกที่เจอ แล้วจบเทิร์น — เงียบ ๆ ไม่มี error ไม่มี note ในบันทึก

**ทำไมถึงร้ายแรง:** นี่คือ*กฎพื้นฐานที่สุด*ของภาษานี้ และฉันหามันเจอด้วยการบังเอิญเท่านั้น
ไม่มีที่ไหนบอก ไม่มี `lessonTh` โซนไหนพูดถึง และตัวตรวจก็ไม่ทัก
กับดักที่ตามมาแน่ ๆ สำหรับมือใหม่:

```python
def turn():
    defend()                      # ← ทำอันนี้อันเดียวตลอดกาล
    attack(weakest(enemies))      # ← ไม่มีวันทำงาน
```

โปรแกรมนี้ผ่านตัวตรวจ ดูสมเหตุสมผล ("ตั้งการ์ดก่อนแล้วค่อยตี") และ**ไม่มีวันโจมตีเลย**
ผู้เล่นจะแพ้แล้วไม่เข้าใจว่าทำไม เพราะโค้ดที่เขาอ่านอยู่ดูถูกต้องทุกบรรทัด

**ข้อเสนอ:** ควรฟ้องตั้งแต่ตอนตรวจ เช่น
"บรรทัด 3-4 จะไม่ถูกทำงาน เพราะ turn() ทำได้หนึ่งการกระทำต่อเทิร์น"

## 7. ข้อจำกัดอื่นที่เจอ (ข้อความดีทั้งหมด)

### ❌ #19 — `return`

```python
def pick():
    return deadliest(enemies)
```
> `SyntaxError` — **"ยังไม่รองรับ return — turn() สั่งการกระทำโดยตรง เช่น attack(...)"**
✅ ชัดเจน บอกด้วยว่าโมเดลการทำงานคืออะไร ("สั่งการกระทำโดยตรง")

### ❌ #20 — สร้างฟังก์ชันเอง

```python
def hitboss():
    attack(deadliest(enemies))
def turn():
    hitboss()
```
> `LockedFeatureError` — **"เฟสนี้สร้างฟังก์ชันเองยังไม่ได้ — ต้องชื่อ turn เท่านั้น (เจอ 'hitboss')"**

⚠️ **ข้อความนี้เสียรูปแบบ** ทุกข้อความ Locked อันอื่นลงท้ายว่า "ต้องผ่านชั้น N ก่อน"
แต่อันนี้พูดว่า "เฟสนี้" ซึ่ง **(ก)** เป็นศัพท์คนทำเกม ผู้เล่นไม่รู้ว่า "เฟส" คืออะไร
**(ข)** ไม่บอกว่าต้องทำอะไรถึงจะปลด — จะปลดที่ชั้นไหน? หรือไม่มีวันปลด? ตอบไม่ได้
ฉันยังไม่รู้คำตอบจนถึงตอนนี้

### ❌ #21 — `while`

```python
while count(enemies) > 0:
```
> `SyntaxError` — **"ยังไม่รองรับ while (การวนแบบไม่รู้จบทำให้เกมค้าง) — ใช้ for แทน"**
✅ ดีมาก — บอก**เหตุผล**ว่าทำไมถึงห้าม ไม่ใช่แค่ห้ามเฉย ๆ ผู้เล่นได้เรียนรู้อะไรบางอย่างไปด้วย
⚠️ ติดนิดเดียว: ตอนนั้นฉันอยู่ชั้น 8 และ `for` **ยังล็อกอยู่ (ต้องชั้น 10)** — แนะนำของที่ยังใช้ไม่ได้

### ❌ #22 — `if True:`
> `SyntaxError` — **"ยังไม่รองรับค่า True โดยตรง — เขียนเงื่อนไขจริง เช่น me.hp_pct < 50"**
✅ มีตัวอย่างโค้ดที่ถูกให้ดู แก้ได้ทันที

### ❌ #23 — ใช้ตัวแปรก่อนสร้าง

```python
def turn():
    attack(boss)
    boss = deadliest(enemies)
```
> `NameError` — "ไม่รู้จัก 'boss' — ใช้ได้เฉพาะ me, enemies, allies, turn_no **และตัวแปรที่สร้างไว้ก่อนหน้า**"
✅ คำว่า "ก่อนหน้า" สอนกฎลำดับการทำงานไปในตัว ฉันเข้าใจทันทีว่าต้องสลับสองบรรทัด

### ❌ #24 — ตั้งชื่อตัวแปรทับของเกม

```python
def turn():
    enemies = weakest(enemies)
    attack(enemies)
```
> `SyntaxError` — **"ตั้งชื่อตัวแปรทับตัวแปรของเกมไม่ได้ ('enemies') — เปลี่ยนเป็นชื่ออื่น เช่น t"**
✅ แก้ได้ทันที และ**เสนอชื่อใหม่ให้เลย** ไม่ต้องคิดเอง

### ✅ คอมเมนต์ `#` ใช้ได้ปกติ ทั้งบรรทัดเต็มและต่อท้าย (ไม่ต้องปลดล็อก)

## 8. 🔴 ฟีเจอร์ที่เกมสัญญาไว้ที่ "ชั้น 13" — แต่ชั้น 13 ไม่มีอยู่จริง

ฉันเล่นจนจบเกมแล้ว:

```
tower      cleared=10/10 completed=True floorRange=[1,10]
greenwood  cleared=4/4   completed=True
isles      cleared=5/5   completed=True
ruins      cleared=5/5   completed=True
frostland  cleared=5/5   completed=True
volcano    cleared=5/5   completed=True
highestFloorCleared: 10
```

**ทุกโซนผ่านหมด ทุกชั้นผ่านหมด `highestFloorCleared` สูงสุดคือ 10**
และถ้าลองท้าชั้นต่อไป:

```
POST /tower/challenge {"floor":11}
→ {"error":"ท้าทายได้เฉพาะชั้น 1 ถึง 10 เท่านั้น"}
```

แต่พอเขียนโค้ดที่มีการคำนวณ ณ จุดที่เล่นจบ 100% แล้ว:

```python
if me.hp_pct < 50 - 10:
```
> `LockedFeatureError` — **"การคำนวณ + - * / และ len() ยังไม่ปลดล็อก — ต้องผ่านชั้น 13 ก่อน"**

**แก้ได้จากข้อความนี้ไหม: ❌ ไม่ได้ และจะไม่มีวันแก้ได้**
`+ - * /` และ `len()` **ถูกล็อกถาวร** เพราะเงื่อนไขปลดล็อกคือชั้นที่เกมไปไม่ถึง
ข้อความบอกทางแก้ที่ทำตามไม่ได้ — สำหรับผู้เล่น มันคือ "ไปเอากุญแจที่ห้องที่ไม่มีประตู"

ผลข้างเคียง: ฉันคำนวณอะไรไม่ได้เลยทั้งเกม เทียบได้แค่กับ*ค่าคงที่ที่พิมพ์เอง*
เช่น `t.hp < me.atk` ได้ แต่ `t.hp < me.atk * 2` ไม่ได้

## 9. 🔴 `has_buff()` — ฟังก์ชันที่ไม่มีใครบอกว่ามี และรับอะไรก็ได้

ฉันเจอฟังก์ชันนี้โดยบังเอิญ ตอนลองเขียน `if me in enemies:`

> `SyntaxError` — "ยังไม่รองรับตัวดำเนินการ 'in' นอกคำสั่ง for — ใช้ `count()`/**`has_buff()`** ตรวจแทน"

`has_buff()` **ไม่เคยโผล่ที่ไหนมาก่อนเลย** ไม่อยู่ใน `lessonTh` ไม่อยู่ใน `/gamedata`
และฉันยิงเดาชื่อฟังก์ชันไป ~35 ชื่อใน §2 ก็ไม่เคยเดาถูก
**ข้อความ error ที่พูดถึงมันโดยบังเอิญ คือที่เดียวในเกมทั้งเกมที่บอกว่ามันมีอยู่**

ลองใช้:
```python
if has_buff(me):
```
> `TypeError` — "has_buff() ต้องการข้อความ แต่ได้รับตัวละคร"
> `TypeError` — "has_buff() ต้องใส่ชื่อเป็นข้อความคงที่ เช่น `has_buff(\"firebolt\")`"

⚠️ ตัวอย่างที่ยกมา (`has_buff("firebolt")`) ใช้ชื่อ**สกิล** มาเป็นชื่อ**บัฟ** — คนละอย่างกัน
เป็นบั๊กแม่แบบข้อความแบบเดียวกับ `.length` ใน #18

แล้วชื่อบัฟที่ถูกคืออะไร? **ไม่มีทางรู้** เพราะ:
```python
has_buff("firebolt") → OK    has_buff("poison")  → OK
has_buff("defend")   → OK    has_buff("stun")    → OK
has_buff("bananas")  → OK    ← ชื่อมั่ว ๆ ก็ผ่าน
```

ต่างจาก `cast()` ที่ตรวจว่าสกิลมีจริงไหม (`cast("bananas")` → `ValueError`)
**`has_buff()` รับทุกอย่าง ไม่ตรวจอะไรเลย** แล้วตอนรบก็เป็น false เงียบ ๆ:

```
โปรแกรม: if has_buff("bananas"): defend() else: attack(weakest(enemies))
บันทึกการรบ: attack บรรทัด 5 × 25 ครั้ง  (บรรทัด 3 คือ defend ไม่เคยทำงาน)
```

ผู้เล่นเขียนเงื่อนไขที่**ไม่มีวันเป็นจริง** โดยไม่มีอะไรบอก

## 11. 🔴 `for` ไม่ได้ทำอย่างที่เขียน (และข้อความ `while` ก็ชี้มาทางนี้)

พอปลด `for` ที่ชั้น 10 ฉันเขียนสิ่งที่มือใหม่ทุกคนจะเขียน:

```python
def turn():
    for e in enemies:
        attack(e)
```
**"ตีทุกตัวในกอง"** — ผ่านตัวตรวจ `OK 200`

บันทึกการรบ:
```
turn 1 attack line 3 → ก็อบลิน   (ตัวเดียว)
turn 2 attack line 3 → ก็อบลิน   (ตัวเดียว)
turn 3 attack line 3 → ก็อบลิน   (ตัวเดียว)
```

ตีตัวเดียวต่อเทิร์นเหมือนเดิม เพราะกฎ "หนึ่งการกระทำต่อเทิร์น" (§6) ตัดลูปตั้งแต่รอบแรก
**`for` จึงแทบไม่มีประโยชน์กับการสั่งโจมตีเลย** — จะใช้มันนับหรือสะสมค่าก็ทำไม่ได้
เพราะ `+ - * /` ล็อกถาวรที่ชั้น 13 (§8)

และตลกร้ายคือ ตอนฉันเขียน `while` เกมตอบว่า **"— ใช้ for แทน"**
ซึ่งตอนนั้น `for` ยังล็อกอยู่ (ฉันอยู่ชั้น 8) และต่อให้ปลดแล้ว มันก็ทำสิ่งที่ฉันต้องการไม่ได้อยู่ดี

## 12. การเล่นจริง: โค้ดช่วยได้จริงไหม?

บันทึกการตัดสินใจ (ไม่ใช่แค่ผลลัพธ์):

| # | โปรแกรม | ผล | เหตุผลที่เปลี่ยน |
|---|---|---|---|
| 1 | `attack(weakest(enemies))` + `defend()` ตอนเลือด < 30% | หอคอยชั้น 2: **เวฟ 1** | แพ้เร็วมาก ดูบันทึกแล้วพบว่า 4 ใน 10 เทิร์นเอาไปตั้งการ์ด |
| 2 | `count>1 → deadliest`, ไม่งั้น `weakest` — **ตัด defend ทิ้ง** | ชั้น 2: **เวฟ 6** | บทเรียนโซนป่าบอกว่า "ทุกเทิร์นที่ defend คือศัตรูอีกตัวที่ยังไม่ตาย" ลองตัดทิ้งแล้วดีขึ้นทันที |
| 3 | เดิม + เลเวลเพิ่ม | ชั้น 2: **ผ่าน** | — |
| 4 | `count>2 → deadliest`, `elif hp<25% → defend` | ภูเขาไฟ d4: **เวฟ 3** | เอา defend กลับมาแล้วแย่ลงอีก |
| 5 | `attack(deadliest(enemies))` ล้วน | ภูเขาไฟ d4: **เวฟ 3** | ยังไม่พอ |
| 6 | `t = weakest(enemies)` · `if t.hp < me.atk: attack(t)` · `else: attack(deadliest(enemies))` | ภูเขาไฟ d4: **เวฟ 7** | **นี่คือจุดที่โค้ดสร้างความต่างจริง** — เก็บตัวที่ตีทีเดียวตายก่อนเพื่อลดจำนวนศัตรู ที่เหลือทุ่มใส่ตัวที่ตีแรงสุด |

**บทเรียนที่เกมสอนฉันได้สำเร็จจริง ๆ:**
1. `defend()` เป็นกับดัก — บทเรียนโซนป่าพูดไว้ตรง ๆ และบันทึกการรบพิสูจน์ให้เห็น
2. เลือกเป้าหมายสำคัญกว่าเลเวล — เวฟ 1 → เวฟ 6 มาจากการเปลี่ยนคำเดียว (`weakest` → `deadliest`)
3. บันทึกการรบบอก **หมายเลขบรรทัด** ของทุกการกระทำ (`L3`, `L5`) — **ฟีเจอร์ที่ดีที่สุดในเกม**
   ตอนแพ้ที่ภูเขาไฟ ฉันเห็น `t19 [newbie] defend L5` แล้วรู้ทันทีว่า "บรรทัด 5 คือตัวฆ่าฉัน"
   ไม่ต้องเดา ไม่ต้องอ่านโค้ดซ้ำ — มันชี้ให้เลย นี่คือการสอนที่ได้ผลที่สุดในเกมนี้

**แต่:** ข้อ 3 ใช้ได้ก็ต่อเมื่อ*แพ้* ตอนชนะไม่มีใครบอกว่าโค้ดห่วย (ดู §4.3)
และตอนต้นเกมชนะง่ายเกินกว่าจะได้เรียนรู้อะไร

## 13. สรุป: เด็ก 15 ที่เพิ่งหัดเขียนโค้ด ผ่านเกมนี้เองได้ไหม?

**ได้ — แต่ผ่านโดยไม่เข้าใจ**

**ผ่านได้แน่** เพราะโปรแกรมเริ่มต้น (`attack(weakest(enemies))`) ผ่านครึ่งเกมได้เอง
และฟาร์มเลเวลชดเชยโค้ดห่วยได้เกือบทุกจุด ฉันพิสูจน์แล้วว่า**ชนะ 10 เวฟได้โดยไม่โจมตีเลยสักครั้ง**

**แต่ "เข้าใจ" ไม่ได้** ด้วยสามเหตุผล:

1. **ไม่มีที่ไหนให้ดูว่าเขียนอะไรได้บ้าง** ข้อความ error ไล่ไป "หน้าช่วยเหลือ" ซ้ำ ๆ
   แต่ผ่าน API ไม่มีหน้านั้น ฉันได้รายชื่อฟังก์ชันมาด้วยการ*ยิงเดา 35 ชื่อในโปรแกรมเดียว*
   แล้วดูว่าบรรทัดไหนไม่มี error — เด็ก 15 ไม่คิดวิธีนี้ออก เขาจะติดอยู่กับ 2 ฟังก์ชัน
   ที่เห็นในโปรแกรมเริ่มต้น แล้วไม่รู้เลยว่ามี `strongest` `fastest` `count` `has_buff` อยู่

2. **ความผิดที่ไม่ส่งเสียง มีเยอะกว่าความผิดที่ส่งเสียง**
   `attack(me)` ผ่านแล้วแอบไปตีศัตรูแทน · เขียน `attack()` สามบรรทัดแต่ทำงานบรรทัดเดียว ·
   `for` วนแล้วตีตัวเดียว · `has_buff("bananas")` เป็นเท็จตลอดกาล · `cast("heal")` ร่ายสกิลที่ไม่ได้มี
   ทุกอันได้ `OK 200` เหมือนกันหมด เด็กจะสร้างโมเดลในหัวที่ผิดตั้งแต่ชั่วโมงแรก
   แล้ว**ไม่มีอะไรมาแก้ให้** จนกว่าจะแพ้หนัก ๆ ตอนท้าย ซึ่งตอนนั้นห่างจากต้นเหตุมากแล้ว

3. **เกมสัญญาแล้วไม่ทำตามอย่างน้อยหนึ่งเรื่อง** `+ - * /` และ `len()` บอกว่าปลดที่ชั้น 13
   แต่เกมมีแค่ 10 ชั้น เด็กที่ตั้งใจจะไล่เก็บให้ครบจะฟาร์มหาสิ่งที่ไม่มีอยู่

**สิ่งที่เกมทำได้ดีจริง ๆ และควรเก็บไว้ทั้งหมด:**
- ข้อความ `LockedFeatureError` แบบ "ฟีเจอร์ X ยังไม่ปลดล็อก — ต้องผ่านชั้น N ก่อน"
  รูปแบบนี้เปลี่ยน "ทำไม่ได้" เป็น "ยังไม่ถึงเวลา" ซึ่งต่างกันมากในใจคนหัดใหม่
- ข้อความที่**เดาเจตนาถูกแล้วยกโค้ดที่ถูกมาให้ดู** (`=` vs `==`, `me.def` → `me.defense`,
  `cast(...)` ยกตัวอย่างเต็มบรรทัด) — สามอันนี้คือมาตรฐานที่ข้อความอื่นควรไปให้ถึง
- **ลิสต์ตัวเลือกในข้อความ** (`ใช้ได้เฉพาะ me, enemies, allies, turn_no` /
  `ใช้ได้แค่ hp, mp, hp_pct, ...`) — ฉันเรียนรู้ภาษานี้จากสองข้อความนี้มากกว่าจากอย่างอื่นทั้งหมด
  **ถ้าทำแบบเดียวกันกับ "ไม่รู้จักฟังก์ชัน" ปัญหาใหญ่ที่สุดของเกมจะหายไปทันที**
- **หมายเลขบรรทัดในบันทึกการรบ** — ดีที่สุดในเกม ทำให้ "แพ้" กลายเป็นบทเรียนแทนความหงุดหงิด
